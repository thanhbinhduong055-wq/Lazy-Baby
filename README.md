# 懒人宝 · SillyTavern 剧情记忆扩展

把旧聊天整理为可编辑的记忆草稿，确认后写入角色或聊天世界书，自动隐藏已总结楼层，保留最近十层原文。使用酒馆当前连接的模型，无需额外 API Key，也不需要酒馆助手、Tampermonkey 或服务端插件。

**v1.1.0**：修复局域网 HTTP 等环境中 `crypto.subtle` 不可用引发的 `digest` 报错；增加角色世界书、可编辑预览、短提示词与重新生成。新版不再生成后立即写入，必须点击“确认写入世界书”。

## 功能

| 需求 | 实现 |
| --- | --- |
| 一键总结前文 | 固定输出时间、地点、人物、剧情摘要、角色表、当前角色状态六个栏目 |
| 写入世界书 | 默认写入当前角色绑定的主世界书，也可选择聊天世界书，回忆条目设为蓝灯常驻 |
| 自动选择或创建 | 自动复用本聊天已有回忆；无条目则创建，无聊天世界书则创建并绑定 |
| 手动选择 | 下拉框选择目标世界书中的现有条目，也可新建记忆条目 |
| 预览与编辑 | 生成后可直接编辑条目名称、记忆正文和附带提示词，确认前不修改世界书或隐藏楼层 |
| 重新生成 | 使用同一批原始素材及最新整理要求生成另一版，失败时保留手动编辑的草稿 |
| 简短提示词 | 分别提供可编辑的总结要求和写入条目正文开头的连续性提示词 |
| 控制详细程度 | 精简、标准、详细三档；支持独立设置回忆 Token 上限 |
| 自动隐藏 | 世界书保存并通过服务器回读校验后，隐藏已总结楼层 |
| 保留最近十层 | 最后十条消息不参与本次总结，不会被插件隐藏 |
| 恢复原文 | 一键恢复本插件隐藏过的楼层，不改动玩家原先手动隐藏的楼层 |

角色状态包含位置、身体、情绪、目标、持有物；未交代的内容要求模型注明“未交代”。生成时检查六项结构和长度。人工编辑后允许自定义正文格式，保存只检查正文非空和总 Token 上限。请在预览时核对事实，插件不能自动证明模型没有遗漏或误解剧情。

## 安装

### 从 GitHub 安装（推荐）

在酒馆中打开“扩展”→“安装扩展”，粘贴以下仓库地址并安装，然后刷新网页：

```text
https://github.com/thanhbinhduong055-wq/Lazy-Baby
```

在扩展面板展开 **懒人宝 · 剧情记忆** 即可使用。

已安装旧版：在酒馆扩展管理中更新 `Lazy-Baby`，然后强制刷新网页（Windows 常用 Ctrl+F5）。看到“生成记忆草稿”“重新生成”“确认写入世界书”三个按钮，即为新版流程。

### 本地安装包

1. 解压 `lanrenbao-v1.1.0.zip`，得到 `lanrenbao` 文件夹。
2. 把整个文件夹复制到你的 SillyTavern 安装目录下：

   ```text
   SillyTavern/
   └─ public/
      └─ scripts/
         └─ extensions/
            └─ third-party/
               └─ lanrenbao/
                  ├─ manifest.json
                  ├─ index.js
                  ├─ core.js
                  ├─ sha256.js
                  └─ style.css
   ```

3. 刷新酒馆网页。如果扩展没有显示，重启酒馆再刷新。
4. 打开“扩展”面板，展开 **懒人宝 · 剧情记忆**。

这是前端扩展，不能把 ZIP 作为角色卡或世界书导入，也不放在服务器 `plugins` 目录。

仓库地址：[Lazy-Baby](https://github.com/thanhbinhduong055-wq/Lazy-Baby)。`manifest.json`、`index.js`、`core.js`、`sha256.js`、`style.css` 保持在仓库根目录，支持酒馆直接安装。

## 使用

1. 打开角色聊天或群聊，并连接一个可用的生成模型。
2. 默认写入“角色世界书”，请先确认角色已绑定主世界书；群聊可改用“聊天世界书”。回忆条目可选择自动复用或“新建记忆条目”。
3. 选择详细程度，默认是“标准”，回忆上限默认 **1200 tokens**。
4. 根据需要修改“总结提示词”，点击 **生成记忆草稿**。此时不会新建条目或隐藏楼层。
5. 在 **预览与编辑记忆** 中修改条目名称、正文及附带提示词。不满意可点击 **重新生成**，它会使用原始素材重新整理，成功后替换正文的手动修改；失败或取消保留旧草稿。
6. 点击 **确认写入世界书**。最终写入内容为“简短提示词 + 编辑后的正文”；总 Token 再次检查通过、服务器保存并回读一致后，才自动隐藏已总结楼层。

草稿仅保留在当前页面内存中；刷新页面或切换聊天会清空。已写入后“重新生成”按钮禁用；若要重写已保存记忆，请按下文“世界书选择与重建”操作。编辑或续聊导致素材变化时，旧草稿不能直接保存，请重新点击“生成记忆草稿”。

默认随记忆写入的短提示词为：

> 以下是已发生的剧情回忆。请维持人物关系与事件连续性，当前状态以最近对话为准，不要重复演绎旧剧情。

可直接修改或清空该提示词；它与用于指导总结的“总结提示词”互相独立。

例如聊天共有 35 层，本次整理第 1–25 层，保留第 26–35 层。继续聊了 8 层后，下次会把第 26–33 层与旧回忆合并，保留最新第 34–43 层。不会把每次回忆无限追加为越来越长的文本。

**一条用户消息或角色消息算一层，不是一问一答算一层。** 系统/手动隐藏消息和空消息不作为新素材。聊天数组的最后十条消息作为保留边界；原来已手动隐藏的消息保持原状态。

“隐藏”使用酒馆原生 `is_system` 标记：消息仍在聊天记录中，通常呈隐藏/弱化样式，不再作为普通历史发给模型。这不是删除，也不是清空屏幕。

## Token 与输入预算

- 精简：优先关键事件和当前状态。
- 标准：增加因果、关系变化、承诺、道具流转和未解决线索。
- 详细：进一步保留动机、事件顺序、重要言语含义和伏笔。
- 回忆上限支持 256–8000 tokens，包含记忆正文和附带提示词，按酒馆当前分词器检查。低上限可能无法容纳完整栏目，此时停止写入，请提高上限。
- 每次输入预算默认 6000 tokens，包含整理指令、旧回忆与本批素材。还会根据酒馆当前上下文长度，为输出预留空间。
- 长聊天自动分批，多个批次可能消耗多次模型调用。单层过长会明确报错，插件不会偷偷截断素材。
- 输出超限时压缩重试一次；仍超限或缺少必需栏目则停止，不隐藏楼层。提供商实际计数可能与酒馆分词器不同。

回忆设为常驻激活并忽略世界书预算，确保它不会因普通世界书预算不足而被跳过；**它仍会消耗模型总上下文**。角色设定、其他扩展、提示词模板和模型服务自身限制也会占用上下文。插件不修改你的模型连接或全局预设。

## 世界书选择与重建

自动模式只复用带有本插件标记、属于当前聊天的活跃回忆，不会按“记忆”“回忆”等模糊名称误覆盖设定。下拉框可手动选择现有条目；此操作会将原内容一并整理，并把该条目改为常驻回忆。

插件支持两种位置：**角色世界书**读取当前角色绑定的主世界书；**聊天世界书**读取当前聊天绑定的世界书。要换一本书，先在酒馆原生对应入口重新绑定，再点击“刷新条目”。角色尚未绑定世界书时会提示先绑定，不会悄悄写入另一部书；聊天模式未绑定书时，会在确认写入阶段自动创建并绑定。

同一角色书可以保存多个聊天的回忆。插件通过酒馆的 `WORLDINFO_ENTRIES_LOADED` 事件，仅让当前聊天的插件回忆参与扫描，普通角色设定不变。隔离依赖插件启用；若停用或卸载插件，需在世界书中自行禁用不应激活的回忆。缺少该事件的旧版酒馆不能使用角色世界书模式。

要重写整段回忆，例如改过旧楼层、切换过已归档回复，或希望提高详细程度：

1. 点击 **恢复插件隐藏楼层**。
2. 下拉选择 **新建记忆条目**。
3. 调整参数后生成草稿、预览编辑并确认写入。

新回忆保存时会禁用同一世界书内本聊天之前的插件回忆，旧条目保留以便查看。恢复楼层本身不会禁用回忆，因此恢复后可能暂时同时发送原文和回忆。没有新增旧楼层时，普通总结按钮不会重复调用模型；需要重新总结请按上述步骤新建。

## 异常处理

- 保存世界书后会从服务器重新读取并比较，不依赖本地缓存。失败时停止隐藏，并清除可能不一致的世界书缓存。
- `crypto.subtle` 不可用时自动改用本地 SHA-256 实现，摘要与旧版完全一致，无需重建已有回忆。相关浏览器限制见 [MDN SubtleCrypto](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto)。
- 总结期间若切换聊天、编辑消息或更换世界书绑定，结果停止提交或停止后续隐藏。请尽量等整理完成再继续聊天。
- “取消后续处理”不会强行中断正在进行的模型请求，当前请求可能仍计费。已发送到服务器的写入不能被撤回；取消会阻止后续隐藏。
- 若保存已完成但后续中断，世界书可能已有回忆而原文仍显示。这时可直接检查条目；要完整重做，可新建回忆。
- 隐藏/恢复使用酒馆自身聊天保存接口，该接口可能在内部吞掉网络错误。若酒馆提示聊天保存失败，解决连接问题后重新保存聊天；世界书回忆与原文都不会被插件删除。
- 不支持多个浏览器标签页同时编辑同一世界书的原子事务。生成结束后会重读世界书并保留其他条目的变更，但不能替代服务器锁。

```sh
npm test
npm run check
```

浏览器模拟测试可运行 `npm run preview:test`，打开终端输出的本地地址。此页面使用虚构消息和模拟模型，不访问真实酒馆、凭据或外部模型服务。

聊天素材仅通过酒馆已有模型连接生成总结；插件不包含遥测或额外外部服务。
